# Code of Conduct

pwauto follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and patient. Many users are testers who are new to code.
- Criticise ideas and code, not people.
- No harassment, insults, or discrimination of any kind.
- Do not publish private information of other people.

The full text of the Contributor Covenant applies to all project spaces: issues, pull requests, discussions and code review.

## Report a problem

Contact the maintainer privately through the [GitHub profile of the project owner](https://github.com/quark-sri). Do not open a public issue for a conduct report. The maintainer reads each report, keeps the reporter's name private, and answers with the action taken.

## Enforcement

The maintainer can remove comments, commits and issues that break this code, and can block a person from the project for a time or permanently, as described in the enforcement guidelines of the Contributor Covenant.
